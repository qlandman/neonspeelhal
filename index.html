Zet je eigen game erbij

Elke game is één blokje code in de lijst GAMES in deze pagina. Een game kan ook een losse pagina zijn: zet het bestand in de map games/ en geef het blokje een src in plaats van create — zo draait Hexdrift hier. Vraag Claude om een nieuwe game en die schuift er zo tussen.

  1. Geef de game een id, titel, korte omschrijving en tags.
  2. Teken een bewegend voorbeeldplaatje in thumb() — dat is wat je op de kaart ziet.
  3. Zet de spellogica in create(api) met een update(dt) en draw().
  4. Roep api.setScore(n) en api.gameOver(n) aan; records worden vanzelf bewaard.
{
  id:'mijngame',
  title:'Mijn Game',
  sub:'Korte omschrijving.',
  tags:['Arcade'],
  color:'#FFC63D',
  keys:['WASD rijden','Klik vuren'],
  thumb:function(c,w,h,t){ /* preview */ },
  create:function(api){
    var x=600;
    return {
      update:function(dt){ x+=60*dt; api.setScore(x|0); },
      draw:function(){ api.clear('#070613'); }
    };
  }
}
Alles draait in de browser — geen server, geen account, geen tracking.
Zet de map met index.html en games/ op GitHub Pages of Netlify en de speelhal staat online voor iedereen.
